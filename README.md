# Swiggy-Raw-Data-Excel-Dashboard
Developed an interactive Swiggy Sales Analysis Dashboard in Microsoft Excel using raw sales data. The dashboard presents key performance indicators, sales trends, customer ratings, order metrics, food-type analysis, and state-wise sales distribution.
Key Features
- KPI cards for Total Sales, Average Rating, Average Order Value, Rating Count, and Total Orders.
- Monthly and daily sales trend analysis.
- Sales breakdown by food type, state, and city.
- Quarterly comparison of sales, ratings, and orders.
- Interactive slicers for months, categories, and restaurants.
- Tools Used: Microsoft Excel, PivotTables, PivotCharts, Slicers, Data Cleaning, and Data Visualization.
Objective: Transform raw sales data into an interactive dashboard to identify sales patterns, compare performance, and support data-driven business decisions.
